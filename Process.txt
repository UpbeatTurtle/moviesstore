Video 7 - Report Inapropriate comments
    When implementing this I had a few different ideas. I didn't want for it to simply delete the comment when reported because that could be abused and perfectly good comments woudl be deleted.
    I started by implmementing a simple report button (with no functionality) on each comment. I innitialy had it so any user (logged in or not) could click report. But, I decided to make it so only users could report because non-users may troll the system.
    Also, I made it so you don't see a report button on your own comment because why would you report yourself.
    I added a new attribute to each comment called "reports", and if a comment is reported, the report counter would go up.
    After testing it out, I realized it wasn't clear that a report went through, so I made a secondary page that a user would be linked to when clicking the report button that made it clear that the report went through.
    I also slightly edited the UI for the admin, so they could see the number of reports a comment has without needing to clicking on the comment itself
